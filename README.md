## ⚡ Running Locally

### Option 1: One-Click (Windows)
Double-click `start-server.bat` in this folder. It automatically starts the server and opens `http://localhost:3000`.

### Option 2: Terminal
```powershell
python serve.py
```
Open **`http://localhost:3000`** in any web browser.

---

## 📁 Project Structure
- `index.html` - Main portfolio webpage
- `styles.css` - Custom typography (Roboto & JetBrains Mono), spacing rules, animations
- `script.js` - Dynamic clock, smooth scrolling, email copy tooltip, mobile navigation
- `assets/` - Profile photo, resume PDF, and placeholder SVG assets
- `serve.py` - Local UTF-8 web server
